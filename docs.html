Functions Reference

Explore the available methods to load animations, modify the skeleton, and chain movements.

bvh( "name" )

Loads and initializes a pre-recorded animation to apply it to the skeleton.

[bvh("surprise")]
Parameters: "name" (string with the exact name of the animation file).
Check the Movement Catalog to see all available animations.

bvh( "dummy" )

Generates a static skeleton in a T-pose.

[bvh("dummy")]
Parameters: No additional parameters required.

.joints( size )

Modifies the size of the spheres that represent the skeleton's joints.

[bvh("surprise").joints(2)]
Parameters: size (numeric value defining the scale).

.bones( thickness) //default length = 1
.bones( thickness, length )

Adjusts the thickness and length of the bones connecting the joints.

[bvh("surprise").bones(2, 1)]
Parameters: thickness (bone width), length (distance multiplier between connections, defaults to 1 if omitted).

.color( c1 )
.color( c1, c2 )

Applies a solid color to the skeleton, or generates a gradient if two colors are specified.

[bvh("surprise").color("red", "blue")]
Parameters: c1 (main color in text or hex format), c2 (secondary color to create the gradient).

.trail( frames )

Creates a visual trail by cloning previous frames to show the movement trajectory.

[bvh("surprise").trail(20)]
Parameters: frames (integer indicating how many previous steps form the trail).

Chaining ( [] > [] )

Links multiple animation blocks sequentially. When the first animation finishes, the skeleton will automatically transition into the next one.

[bvh("surprise")] > [bvh("froging").color("red")]
Syntax: Use the > symbol between two completely closed blocks ([] > []) to concatenate them.
