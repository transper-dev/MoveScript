bvh() dummy() joints() bones() color() trail() Catálogo Movimientos

bvh( nombre )

Carga e inicializa una animación pregrabada para aplicarla al esqueleto.

[bvh("surprise")]
Parámetros: nombre (cadena de texto con el nombre del archivo de animación, sin la extensión .bvh).

bvh( "dummy" )

Genera un esqueleto estático en pose T (T-pose). Útil para visualizar modificaciones de diseño sin el movimiento de la animación.

[bvh("dummy")]
Parámetros: No requiere parámetros adicionales, funciona pasando "dummy" a la función principal.

.joints( tamaño )

Modifica el tamaño de las esferas que representan las articulaciones del esqueleto.

[bvh("surprise").joints(2)]
Parámetros: tamaño (valor numérico que define la escala de la articulación).

.bones( grosor, [longitud] )

Ajusta el grosor y, de forma opcional, la longitud de los huesos que conectan las articulaciones.

[bvh("surprise").bones(2, 1)]
Parámetros: grosor (ancho del hueso), longitud (parámetro opcional para alterar la distancia entre conexiones).

.color( color1, [color2] )

Aplica un color sólido al esqueleto, o genera un gradiente si se especifican dos colores.

[bvh("surprise").color("red", "blue")]
Parámetros: color1 (color principal en formato texto o hex), color2 (color secundario opcional para crear el gradiente).

.trail( fotogramas )

Crea una estela visual clonando los fotogramas anteriores para mostrar la trayectoria del movimiento.

[bvh("surprise").trail(20)]
Parámetros: fotogramas (número entero que indica cuántos pasos previos forman la estela).
