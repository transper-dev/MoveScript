bvh() dummy() joints() bones() color() trail() Chaining

bvh( name )

Loads and initializes a pre-recorded animation to apply it to the skeleton.

[bvh("surprise")]
Parameters: name (string with the name of the animation file).

bvh( "dummy" )

Generates a static skeleton in a T-pose.

[bvh("dummy")]
Parameters: No additional parameters required.

.joints( size )

Modifies the size of the spheres that represent the skeleton's joints.

[bvh("surprise").joints(2)]
Parameters: size (numeric value defining the scale).

.bones( thickness, [length] )

[bvh("surprise").bones(2, 1)]

.color( c1, [c2] )

[bvh("surprise").color("red", "blue")]

.trail( frames )

[bvh("surprise").trail(20)]
